# 多氟多（002407.SZ）2026H1 财报精读

> **数据截止日：2026-09-12（Asia/Shanghai）**
>
> **资料可得性：A级。**已取得[巨潮完整中报](https://static.cninfo.com.cn/finalpage/2026-08-18/1225478600.PDF)（2026-08-18，199页）及[减值公告](https://static.cninfo.com.cn/finalpage/2026-08-18/1225478604.PDF)。中报未经审计。
> 本报告用于学习与研究，不构成投资建议。

## 结论

**判定：超预期，但利润质量未通过加仓门槛。**六氟磷酸锂景气使利润表转强，然而 CFO/归母仅 65.72%、资本开支后自由现金流为负，应收快于收入增加、库存显著抬升、净债务仍重，且关联交易规模扩大。投资论文为**削弱**。已持有者应**减至严格周期仓位，不加仓**。

## 二、本期最重要的三项变化

1. **利润修复没有转成自由现金流。**CFO 虽同比增加 3.10亿元，却比归母利润少 1.75亿元；资本开支 4.85亿元后 FCF 为 -1.48亿元。对高资本开支、强周期材料业务，这是比利润同比更重要的约束。

2. **收入增长伴随营运资本更快膨胀。**应收较年初增加 14.66亿元，增幅 86.71%，存货增加 7.04亿元，增幅 40.36%。公司解释为应对下游需求增加而备货；该解释合理但必须由下半年收现和库存去化证明。

3. **债务与关联方暴露没有随利润一并消失。**短借加全部长期借款约 88.37亿元，高于可自由动用的现金及等价物；关联采购 5.89亿元、关联销售 3.17亿元，且关联方资产/工程采购 1.41亿元。它们不是违规证据，却提高了资本配置与定价审阅的必要性。

## 三、现金流、库存与减值复核

| 核查项 | 原始财报事实 | 判断 |
|---|---:|---|
| CFO 与归母净利 | 3.3637 / 5.1186亿元 | **65.72%**，低于 80%警戒线 |
| 简化 FCF | 3.3637 - 4.8477 = -1.4840亿元 | 仍需外部融资或既有现金支持扩张 |
| 存货总额 / 准备 / 净额 | 25.11 / 0.63 / 24.48亿元 | 净额 +40.36%，准备余额仅 +3.39% |
| 本期存货跌价计提 | 0.2607亿元 | 上年同期 0.0898亿元；+190.2% |
| 资产减值损失 | 0.3162亿元 | 存货 0.2607亿元、固定资产 0.0555亿元 |
| 信用减值损失 | 0.8307亿元 | 上年同期 0.4163亿元；应收增长已反映到损失计提 |

存货中原材料和库存商品同步增加。准备绝对额并未随存货同比例增加，而本期跌价计提已明显上升；这组合更像“需求兑现前的押注”，并非可以放心忽略的库存改善。

关联交易附注没有给出不公允定价的直接证据，且披露称均未超额度；但同一控制人体系内的采购、销售、工程和应收同时存在，审阅不能停留在“已履行程序”。下一期应要求交易价格可比、关联方回款和工程验收证据。

截至截止日，另有[2026-09-11关联交易公告](https://static.cninfo.com.cn/finalpage/2026-09-11/1225558574.PDF)：公司放弃同位素科技增资优先权，持股由 51% 降至 46.36%但仍并表。此为期后事项，不用于 H1 业绩归因，但应纳入治理跟踪。

## 五、管理层表述与承诺追踪

管理层对利润改善的归因清晰：下游储能和新能源汽车需求、六氟磷酸锂供需优化、上游一体化压低成本。表述的缺口在于没有量化说明利润中有多少来自价格、成本与产品结构，也没有用回款和库存周转来证明增长质量。

没有可与此前量化指引逐项对比的正式公司利润指引；本报告不把行业景气叙事视作业绩承诺已兑现。

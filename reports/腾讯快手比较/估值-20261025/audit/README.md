# 核验范围与已知限制

结论：**PASS_WITH_EXPLICIT_SCOPE**。此状态只针对下述事实核对与计算，不代表投资预测通过审计。

## 三轮复核

1. 原始财报重建TTM、现金流、资金及经济股本，独立数据库核对关键收入、归母利润和CFO。快手数据库资本支出滞后、腾讯FCF与现金定义差异均保留并拒绝混用。历史背景表部分数值本轮仅单源，报告明示。
2. 未参与主建模者使用反向递推DCF和Newton IRR独立复算312项，检查年度现金账与股东权利。修正腾讯少数股东认沽与归属比例的潜在双扣；修正可灵员工激励不承担现金投入时的补资份额。六个主站FCFF情景另经共享`company_valuation.py`核验，差异小于1e-30模型单位。
3. 重做资本成本/终值、净再投资、主站利润率、可灵归属/补资、融资实缴上限、分配政策、反向增长和主观概率排名敏感性。独立叙述审读纠正了12%回报门槛与买价观察线的不一致。

## 报告抽样

运行`report_audit.py extract --ratio 0.15 --seed 42`。工具提取225项，并因自身30项上限抽30项，实际覆盖13.33%，不是全量15%。30项全部分配处理：11项事实或财务派生值、12项模型结果、5项预测/资产假设、2项日期解析碎片。

- [facts.json](facts.json)及[facts-verdict.txt](facts-verdict.txt)：实际原件、独立数据库或原件财务桥；单源条目标明，不将同一公告镜像充作独立来源。
- [calculations.json](calculations.json)及[calculations-verdict.txt](calculations-verdict.txt)：模型条件结果的算术核对，不能当外部事实验证。
- [sample-dispositions.json](sample-dispositions.json)：30项完整分类，假设未冒充事实PASS，日期碎片未当财务数据。
- [engine_reference.json](engine_reference.json)：六个核心FCFF情景的共享引擎完整输入/输出；可灵资本调用及失败零终值由独立自定义模型覆盖。
- [financial-rigor.txt](financial-rigor.txt)：共享工具市值、TTM、跨源核对；共享calc存在浮点展示尾差，主模型及独立复核均使用Decimal，未凭该展示声称无限精度。
- [status.json](status.json)：最终报告哈希、覆盖和排除清单。

主估值、资产桥、概率、现金账和两段持有期不只依靠抽样，全部进入独立计算检查。退出目标价、股息与IRR最终展示值与模型核对；最终审读后修正了快手累计股息的旧舍入数字。

## 不能据此推断的事项

预测增长、利润率、AI回报、资本成本与情景概率不是事实；不能把代码检查当作商业预测正确。完整的实时稀释股本、腾讯投资组合十月重估、六月至十月资产现金变动、可灵单体成本与资金实际到账没有完整独立验证。统一的零净回购、部分分红、无息留存现金是假设，结果不等于真实资本配置路径。

模型不覆盖全部极端监管、产权、治理与融资断裂情景；腾讯悲观十年正IRR不意味着保本。两家公司存在交叉持股及共同宏观风险，情景概率不构成统计置信度。

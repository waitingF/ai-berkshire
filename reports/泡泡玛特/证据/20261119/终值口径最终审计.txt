【C1】币种一致性 — r 与 g 必须用同一个币种
     HKD 口径基准：港币与美元挂钩，口径同 USD
     r 合理区间 [9.0%, 11.5%]   g 上限 4.0%   Rf 4.70%
     → ✓ 通过

【C2】分母宽度 — r-g 至少 5 个百分点
     悲观  g= 1.0%  r-g= 9.0pct  PE=     10.6x  g+0.5pct → 10.9x (+3%)  
     基准  g= 2.0%  r-g= 8.0pct  PE=     11.2x  g+0.5pct → 11.7x (+4%)  
     乐观  g= 3.0%  r-g= 7.0pct  PE=     12.1x  g+0.5pct → 12.7x (+5%)  
     → ✓ 通过

【C3】离散风险归属 — 退市/VIE/地缘/监管必须归情景，不得进 r 或 β
     ✓ IP需求衰退 → 情景
     ✓ 海外店效及关税冲击 → 情景
     ⚠ 全面禁运或严重安全事故 → 未建模
     ⚠ IP权利重大争议 → 未建模
     β = 1.0（默认值，无需理由）
     → ✓ 通过

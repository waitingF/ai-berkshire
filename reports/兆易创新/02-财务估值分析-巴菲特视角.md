# 兆易创新财务与估值分析

> 数据截止：2026-11-20，Asia/Shanghai；财务截止2026-09-30，三季报未经审计。统一行情快照：2026-11-20 13:46:32，A股603986报206.32元。用户成本440元、当前约占投资资产50%、无融资；用钱期限未确认。信息丰富度A。

**财务与估值评分：2.5/5。** 当期收入、扣非利润和现金回款很强，偿债风险较低；估值的主要难点是周期中枢，而非会计利润是否存在。现价已经大幅消化此前高估值，但正常化盈利仍缺少安全边际证据。半仓持有人应先减集中度。

## 四、当前估值究竟是多少

使用2026年9月底、且行情源确认的总股本703,971,427股；未将拟注销但尚未注销的回购股先行扣除。

| 估值口径 | 计算基础 | 结果 |
|---|---|---:|
| A价等值总市值 | A股206.32元乘A+H总股本 | 1,452.43亿元 |
| TTM归母利润 | 2025全年+2026前三季度−2025前三季度 | 116.30亿元 |
| TTM归母PE | 使用当前总股本归一化每股利润 | 12.49倍 |
| TTM扣非利润 | 同上滚动公式 | 98.61亿元 |
| TTM扣非PE | 不把九个月利润误称全年利润 | 14.73倍 |
| 九个月扣非简单年化PE | 九个月扣非乘4/3 | 11.55倍 |
| 每股归母净资产 | 期末归母权益除当前总股本 | 109.14元 |
| PB | 股价除上述BVPS | 1.89倍 |

“A价等值总市值”是统一每股估值口径，**不等于A、H两地分别按各自股价和汇率计量的合计市值**。九个月基本EPS15.83元使用加权股数，不应直接与当前总股本口径的TTM EPS16.52元混用。部分网页展示约9.8倍PE是归母九个月年化口径，和14.73倍TTM扣非PE不冲突。

数据：腾讯与东方财富行情双源，同一盘中时点报206.32元；[快照及链接](核验-20261120/quote-snapshot.json)。行情会变化，本报告未取得当天收盘价。三年/五年历史PE分位及同一正常化口径可比公司估值未充分取得，不输出精确排名；同行利润率证据见行业报告。

## 五、把经营业务和股权资产分开估值

以下全是**静态正常化估值敏感性，不是盈利预测、时点目标或价格底部承诺**。只回答在不同利润中枢与资产折价下，每股价值如何变化。

1. 经营利润起点：九个月扣非年化125.79亿元，近似扣除年化净利息税后3.49亿元，得到122.29亿元、每股17.3720元。净利息税率假设15%，不声称是所有主体实际税率；未取得完整经营/投资税后分部，故只是近似。
2. 主业假设：正常化利润相对上述起点分别下降20%、50%、75%，给22、18、15倍PE。这里“乐观”也假设从极高盈利水平回落；更强景气可能超出模型。
3. 权益资产：517.65亿元减去全部递延所得税负债50.47亿元，暂以467.18亿元为保守参考池，再按80%、60%、30%计值。没有证明全部递延税都属于这一资产池；这是保守统一留税。折价包括估值回撤、流动性和处置限制，不代表预计立刻卖出。
4. 超额现金：各情景仅加80亿元，明显低于账面货币资金；其余留作经营、采购、承诺投资及不确定项目缓冲。其他金融资产不另按面值叠加。未来回购支出、投资和积累现金均可能改变这一假设。
5. PE已代表对正常化盈利的资本化评价，不再任意加一次一年折现。本模型未建立未来现金、投资、分红和回购桥表，因此不计算一年收益率或总回报；现金和股权资产池变化后必须重算。

反向检验：中性资产计值与18倍主业PE不变时，440元需要主业净利润约152.06亿元，高于本次主业年化起点。这不是说440永远回不去，而是“解套”需要盈利、估值或资产计值进一步改善，成本不能制造回报。

## 六、对半仓持有者的财务结论

现价有乐观上行空间，但中性静态估值接近现价，未提供宽裕安全边际，悲观估值差也足够大。没有理由因为“已经跌很多”继续保留50%资产敞口；同样不应忽略已出现的现金盈利和股权资产，轻率认定股票已经没有价值。

建议先卖出现有持仓一半，将仓位从50%降至约25%，再依据用钱期限和承受力向15%—20%调整；达到15%—20%共需卖出现持仓的60%—70%。这是个人风险预算建议，不是根据期望收益优化得出的最优比例。默认出售所得仍计入投资资产、其他价格不变，忽略税费。

具体操作价位与研究节点统一见[最终报告](最终报告.md)，避免多个报告产生互相矛盾的监控区间。没有把440元列为等待卖出的必要条件。

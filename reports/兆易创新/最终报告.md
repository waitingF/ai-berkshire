## 第四步：最强的看多与看空论点

| 看多 | 看空 |
|---|---|
| 全球NOR产品与认证基础，非纯概念公司 | 行业共同超高毛利，持续性无法由品牌保证 |
| 工业、汽车、服务器固件对可靠性和长供货有要求 | 售价与采购成本传导不同步，低成本库存红利可能减弱 |
| 海外产能转移给利基产品留下供给缺口 | 海外退出分产品、分客户，制程迁移及竞争扩供并未消失 |
| 主营扣非利润和CFO均已兑现 | 存货上升快，价格转向可能带来毛利与减值双重压力 |
| 股权投资和现金对股东有真实价值 | 股权估值与主业景气相关，不能视为独立无风险缓冲 |
| 回购在执行，可能增加每股价值 | 创始人减持、关联交易和新增股本要求持续治理检验 |

最可能的分析错误，是把2026年的高景气利润当成新常态；相反方向的错误，是低估国产产品升级使利润中枢永久抬升的可能性。现有数据不足以给二者可靠概率，不编造胜率。

| 失败路径 | 主观风险重要性 | 观察证据与后果 |
|---|---|---|
| 售价回落且上游成本追赶 | 高 | 毛利、扣非和现金流下降；不能只看低基数同比 |
| 备货转为难售库存 | 高 | 周转、库龄、准备、下游订单共同变差 |
| 股权资产估值回撤 | 高 | 净资产减少，主业与资产估值同时承压 |
| 关联采购利益分配不利 | 中高 | 价格、产能优先级、预付和账期明显恶化 |
| 政策或供应链实质受限 | 中高 | 正式公告的限制、停供、客户认证丢失 |

## 第六步：现价是否值得继续重仓

现价206.32元，对应TTM归母PE12.49倍、TTM扣非PE14.73倍、PB1.89倍。并非明显还在按早前的极高估值交易。但PB包含大额股权重估；扣非利润也仍有存储周期，低PE不能单独回答是否便宜。

## 第八步：你的行动清单

**我的暂定建议：先卖出现有持仓一半，将约50%的仓位降至约25%；随后把最终仓位向15%—20%调整。** 达到15%—20%，合计需要卖出当前股数的60%—70%。这是一项风险预算建议，不是精确最优仓位。前提是50%为当前市值占比、卖出款仍留在投资资产中、其他资产价格不变，暂不计交易费用。

没有融资，让你有主动决定卖出节奏的空间；不意味着半仓安全。若这只股票从现价再跌30%，半仓会单独拖累整个投资组合约15%；降到20%仓位，同样跌幅拖累约6%，假定其他资产不变。**已经发生的损失无法由不卖而消失，减仓是在限制下一段风险。**

| 你的实际情况 | 行动 |
|---|---|
| 半仓、无融资，资金期限暂不明确 | 先减集中度，不等回到440；暂不补仓摊低成本 |
| 一至两年内有确定资金用途 | 先把所需金额移出股票，不能依赖反弹支付 |
| 资金长期不用，能理解并承受存储周期 | 15%—20%只作暂定上限；余仓仍须持续验证 |
| 再遇明显下跌会影响生活或睡眠 | 目标比例还应更低，可降到小观察仓或退出 |
| 除兆易之外还重仓其他存储、芯片、长鑫相关资产 | 同周期敞口更高，需按组合继续降低上限 |

目前没有充分依据指定某一个技术止损价。第一笔减仓不依赖等反弹；执行可以拆单，但不能把“等待更好的卖点”变成无限延期。后续是否清仓，取决于资金需求、投资理解和证伪证据，不由440决定。

### 统一价位与复核条件

| A股价格/状态 | 空仓者 | 当前持有人 |
|---|---|---|
| 180元及以下 | 只进入完整复核，不自动买入 | 半仓问题仍要处理，不能因触价自动补仓 |

180元取中性静态参考价值约207.53元以下的观察门槛，仍谈不上宽裕安全边际；260元为高于中性参考的主观警戒线。**两个价位都是研究门槛，不能解释成支撑、底部或必然卖点。** 估值参数或股本发生变化时重算，不沿用旧价位。

重新考虑加仓，至少需要：售价/成本正常化后扣非仍可接受；库存与终端销售匹配；现金继续兑现；关联采购条件可解释；更新估值有充足回报。用户达到合理仓位前，不启动加仓。

进一步减仓或退出的证据包括：售价与毛利持续走弱且库存周转恶化；扣非与CFO持续背离；股权资产估值明显回落；采购或供应约束实质恶化；个人资金期限缩短。单次季度波动须解释，不机械用一个指标判死刑。

已将上述180元复核门槛、260元警戒线及2027-01-31人工研究检查日登记到现有兆易创新监控条目。该日期是自定检查日，**不是公司承诺财报日**。届时核新披露、景气、库存、采购、股本及个人增持实际执行；价格由现有每日监控扫描，事件仅保留供人工复核，不新增自动事件通知。

## AI分析置信度与投资确定性

对“当期经营强、半仓集中风险高、不能等440才决策”的判断，证据较充分。对未来盈利中枢、股权资产实际可实现价值和反弹时间，置信度明显较低。投资确定性不会因四个研究角色意见相近而增加；他们可能共同低估或高估同一轮周期。

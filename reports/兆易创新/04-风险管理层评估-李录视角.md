# 兆易创新（603986）风险与管理层研究报告

**研究视角：李录；数据截止：2026年11月20日；财务截止：2026年9月30日。**

用户情况：成本440元，约占投资资产50%，无融资，用钱期限尚未确认。价格采用团队统一快照：2026年11月20日13:46:32，A股206.32元。本文负责风险和治理，完整估值及统一行动方案见同目录综合报告。

风险维度评分：3/5；管理层与股东利益一致性：3/5。评分为主观研究判断，分数越高表示风险越容易控制。

## AI研究偏见自觉

信息丰富度评级为A，公告与媒体覆盖充足。主要偏见风险是把大量重复报道误认为多个独立证据，把业绩高增长视为周期风险已经消失，或因股价大跌倒推公司必然有经营问题。本报告以原始公告核实事实，对金融数据使用东方财富与巨潮交叉检查；无法核实的动机与政策影响保留空白。

现有公告不足以支持“公司经营已经崩坏，因此必须全部清仓”的判断；也不足以支持把50%的投资资产继续压在一只周期股上等待440元解套。首要行动应是减集中度，余仓再由盈利持续性、存货与现金流决定去留。

## 一、440元与当前股价可以直接比较吗

2026年已核实的年度分配为每股现金红利0.75元，5月26日除息，不送红股、不以资本公积转增股本。因此，今年这轮大跌不能用“大比例送转导致名义价格下降”解释。若440是券商当前持仓成本，应优先以券商已调整后的成本计算；若是历史买入价，须核对买入日期和已经收到的历年分红。[公司分派实施公告，2026-05-20](https://static.cninfo.com.cn/finalpage/2026-05-20/1225316589.PDF)、[东方财富交叉来源，2026-05-19](https://finance.eastmoney.com/a/202605193742327637.html)

成本只影响实际盈亏，不能证明股票未来应该回到440元。继续持有的理由必须能够回答：若今天拿到同额现金，是否仍愿意以当前价格买入这么大的仓位。

## 三、管理层能力与治理

现任董事长是朱一明，副董事长、总经理是何卫。何卫2009年加入公司，2023年4月起任总经理；不能沿用过时人物身份。长期任职有利于执行连续性，但能力评价仍应以产品商业化、现金回报和资本配置结果检验。[2025年报，2026-03-31](https://static.cninfo.com.cn/finalpage/2026-03-31/1225061352.PDF)、[2026半年业绩说明会](https://roadshow.cnstock.com/fbh/zycx202606)

朱一明同时担任长鑫科技董事长。兆易与长鑫存在股权投资和DRAM采购代工关系，形成协同，也带来潜在利益冲突。2026年9月追加关联采购额度时，朱一明回避董事会表决；相关议案随后经股东会通过。这些是程序证据，不能单凭“已回避、已通过”证明每笔交易价格均最优。[关联交易公告，2026-09-29](https://static.cninfo.com.cn/finalpage/2026-09-29/1225584778.PDF)、[股东会决议，2026-10-21](https://static.cninfo.com.cn/finalpage/2026-10-21/1225612916.PDF)

资本配置应分别评价：

- 核心研发与产品扩张是否增加长期盈利；
- 对外股权投资是否创造可实现回报；
- 回购价格和注销结果是否提高每股价值；
- 股权激励、新发行和回购注销合并后，每股权益是否改善。

2026年H股发行合计33,253,100股，增加了现金与股本。发行会摊薄原持有人比例，但不能忽略募集现金后直接断言“摊薄了等比例价值”；EPS应使用发行后的加权股数。[工商变更公告，2026-05-30](https://static.cninfo.com.cn/finalpage/2026-05-30/1225339729.PDF)

## 五、目前最值得警惕的经营信号

存货从6月底41.84亿元上升至9月底62.92亿元，精确计算环比增加+50.37%。这可能包含主动备货及采购价格上涨，也可能增加周期逆转时的跌价风险；仅凭存货增加，还不能证明滞销。[三季报](https://static.cninfo.com.cn/finalpage/2026-10-30/1225641959.PDF)、[东方财富财务页面](https://emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/Index?code=SH603986&type=web)

公司自己披露：存储行业处于上行周期，未来供需和价格变化可能压低售价与毛利率；同时存在供应链、研发、汇兑及并购整合风险。[2026半年报，第22—23页](https://static.cninfo.com.cn/finalpage/2026-08-19/1225480384.PDF)

| 风险 | 主观重要性 | 可证伪观察 |
|---|---|---|
| 盈利处于周期高位 | 高 | 实际售价、单季毛利率与扣非利润能否维持，而非只看低基数同比 |
| 存货与跌价 | 高 | 存货周转、库龄和跌价准备；收入放缓时存货是否继续增加 |
| 长鑫采购及利益冲突 | 中高 | 采购条件、预付款、结算期限、关联方毛利分配是否显著恶化 |
| 股权资产重估回撤 | 高 | 股权估值下跌对净资产的影响；是否被错误当作现金安全垫 |
| 供应链及贸易限制 | 中高 | 公司或关键供应商是否正式公告限制、停供或许可变化 |
| 流动性危机 | 当前相对较低 | 可用现金、合同现金需求、有息债务是否发生实质变化 |
| 研发及并购 | 中 | 新产品量产收入、研发回报、商誉与整合损失 |

## 六、怎样把风险判断变成行动

| 用户情形 | 行动判断 |
|---|---|
| 当前50%仓位 | 优先降低集中度，不以“是否能回440”决定卖出 |
| 过渡降仓 | 20%—25%仅作为过渡上限；仍不能视为本报告认可的最终长期仓位 |
| 最终配置 | 与综合报告统一：15%—20%为当前信息下的个人研究判断，不是通用最优仓位；取决于用钱期限、其他资产与风险承受力 |
| 近期需要的钱 | 把所需资金从股票中分离，不让支付需求依赖未来反弹 |
| 可长期不用的余仓 | 接受盈利回落与估值下降同时发生；保留的理由应是保守情景下未来回报仍可接受 |

以卖出资金保留在投资账户、忽略税费和价格变化为前提，从投资资产占比50%降至20%—25%，约须卖出现持仓50%—60%；降至最终15%—20%，约须卖出现持仓60%—70%。这些比例是仓位数学，不是对短期涨跌的预测。

进一步减仓的基本面证据包括：售价和毛利持续走弱、存货周转恶化并伴随跌价、扣非与现金流明显背离、供应链正式受限，以及关联交易条件显著不利。观察这些信号时应使用可比季度口径，避免季节性与账期变化引发误判。

重新提高确信度的证据包括：库存消化与终端销售匹配、现金持续兑现，以及盈利正常化后估值仍有余地。回购、个人增持或股价反弹单独出现，都不足以证明投资论点恢复。

没有依据给出某个技术止损价。当前最有把握的结论是仓位风险过高；经营是否已见顶、股价何时企稳，现有公开资料给不了同等确定性。

## AI分析置信度与投资确定性

对已核对的分派、减持、回购及财务口径，数据置信度较高；对周期持续时间、关联交易的商业最优性、股权资产最终可变现价值和未来政策，置信度较低。用钱期限未确认，因此15%—20%的最终仓位仍需服从资金需求。资料充足不等于未来回报确定。

本项目用于学习和研究，不构成对收益或损失的保证。

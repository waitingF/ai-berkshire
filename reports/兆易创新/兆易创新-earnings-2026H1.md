# 兆易创新（603986.SH / 03986.HK）2026H1 财报精读

> **数据截止日：2026-09-12（Asia/Shanghai）**
>
> **资料可得性：A级。**已取得[巨潮完整中报](https://static.cninfo.com.cn/finalpage/2026-08-19/1225480384.PDF)（2026-08-19，178页）与[港交所英文中期报告](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0818/2026081801933.pdf)。两份正式披露的核心数字一致；中报未经审计。
> 本报告用于学习与研究，不构成投资建议。

## 结论

**判定：超预期。**存储景气带来的收入、扣非利润和经营现金流同时跳升；但归母净利润中有 22.2795 亿元非现金公允价值收益，强 CFO 也有 19.4643 亿元经营性应付增加支撑。投资论文为**部分强化、关联交易维度削弱**。已持有者**持有，不以高景气利润追高加仓**。

## 二、本期最重要的三项变化

1. **扣非也爆发，不能只归因于会计收益。**归母与扣非之间约 19.74 亿元的差额主要对应 22.28 亿元公允价值变动收益（税前）；但扣非利润仍同比增加 43.39 亿元，CFO 也超过扣非利润，景气改善有经营基础。

2. **现金流强度要扣除营运资本的“借力”。**现金流量调节表显示，存货增加占用 12.03 亿元、经营性应收增加占用 1.31 亿元，而经营性应付增加贡献 19.46 亿元。CFO 是真实现金流，不应误读成全部由利润自然转化而来。

3. **长鑫关联采购从附注问题变为核心风险。**向长鑫科技及子公司采购原材料等 19.86 亿元，同比增加 358.2%；期末应付余额 6.88亿元，同比增加 301.8%。供应关系或有商业合理性，但没有披露价格、非关联可比价或结算条款。

## 三、现金流、库存与减值复核

| 核查项 | 原始财报事实 | 判断 |
|---|---:|---|
| CFO 与归母净利 | 60.4834 / 68.5679 亿元 | 88.21%，受非现金公允价值收益拉低 |
| CFO 与扣非归母 | 60.4834 / 48.8303 亿元 | 123.86%，主营利润的现金化通过 |
| 简化 FCF | 60.4834 - 9.4511 = 51.0324亿元 | 为正；不将现金管理与股权投资支出当作资本开支 |
| 存货总额 / 准备 / 净额 | 44.67 / 2.83 / 41.84亿元 | 净额 +36.47%，准备余额反而 -5.44% |
| 资产减值损失 | 0.6978亿元 | 上年同期 0.1732亿元；其中存货 0.5169亿元、固定资产 0.0877亿元、无形资产 0.0630亿元、开发支出 0.0302亿元 |
| 信用减值损失 | 0.0115亿元 | 规模很小；应收增量仍要由 Q3 回款检验 |

存货准备本期计提 0.5169亿元、转回或转销 0.6422亿元、其他减少 0.0376亿元。财报没有把“转回”与“转销”分别量化，也没有逐项说明原因；在库存加速增加、准备余额下降时，这一透明度缺口应保留为风险项。

## 四、关联交易与治理复核

| 项目 | 2026H1 | 审阅结论 |
|---|---:|---|
| 向长鑫科技及子公司关联采购 | 19.86亿元 | 约为收入的 17.17%，同比 +358.2% |
| 对长鑫关联应付账款 | 6.88亿元 | 年初 1.71亿元；应付扩张也是 CFO 的重要支撑背景 |
| 对其他联营企业采购 | 0.047亿元 | 金额较小 |
| 关联销售 | 0.005亿元 | 非主要风险 |
| 关联担保、资金拆借、资产转让/债务重组 | 无 | 财报未披露发生额 |

长鑫被认定为关联方的原因是公司实际控制人、董事长朱一明同时担任其董事长。财报没有发现违规或不公允定价的直接证据；但在采购额和应付快速上升时，缺少可比定价及信用期限披露，足以使治理评分下调一级。

## 五、管理层表述与承诺追踪

管理层把增长归因于存储供给紧张、量价齐升和 MCU 多领域需求，且明确预期下半年 DRAM 价格转为温和上行。这一表述有行业依据，但它也是周期性判断，不能替代库存准备和应付账款的连续数据。

本期没有可与此前量化利润指引逐项比对的正式公司指引；因此不把景气展望记作已兑现承诺。

## 六、结论与下一验证点

| 必答项 | 结论 |
|---|---|
| 财报表现 | **超预期**：收入、扣非利润和 CFO 均显著跃升 |
| 对投资论文 | **部分强化、关联交易维度削弱**：主营现金化强，但循环上行与关联采购集中度需折价 |
| 下一催化剂 | 2026Q3 的 DRAM 价格、库存准备、对长鑫应付余额和现金回款 |
| 已持有怎么办 | **持有，不追高加仓**；若库存准备继续下降而库存/应付继续上升，转为减仓复核 |

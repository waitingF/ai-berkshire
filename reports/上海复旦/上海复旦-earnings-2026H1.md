# 上海复旦（688385.SH / 01385.HK）2026H1 财报精读

> **数据截止日：2026-09-12（Asia/Shanghai）**
>
> **资料可得性：A级。**已取得[巨潮完整中报](https://static.cninfo.com.cn/finalpage/2026-08-18/1225478247.PDF)（2026-08-18，161页）及[公司IR中期业绩公告](https://www.fmsh.com/UpLoadFile/20260818/c_result_submission%20v2.pdf)。两份正式披露对经营现金流均为 7.7013 亿元；中报未经审计。
> 本报告用于学习与研究，不构成投资建议。

## 结论

**判定：符合预期。**归母净利润落在公司此前 8-10 亿元的预告区间内；扣非利润和现金回款确有改善，但表面净利润被 4.6561 亿元的非现金公允价值变动显著抬高。投资论文为**部分强化**：库存去化与核心现金流支持经营修复，惟回款质量和关联销售仍须由 Q3 验证。已持有者**持有、不追高加仓**。

## 二、本期最重要的三项变化

1. **利润表不能直接代表经营兑现。**交易性金融资产公允价值变动收益为 4.6561 亿元，公司称税后约增厚净利润 4.2 亿元；它解释了归母与扣非利润之间的大部分差额。应以扣非利润 +125.88% 和 CFO/扣非 187.0% 来判断主业，而不能把归母 +338.58% 年化。

2. **库存从“数量压力”转向“定价压力”。**存货净额下降 1.01 亿元，但跌价准备反增至 8.0390 亿元，准备率由 23.19% 升至 24.07%。本期新增存货跌价 1,481 万元，远低于上年同期 1.4295 亿元，却不能证明库存风险已经消失。

3. **现金流改善真实，但仍需看回款期限。**CFO 增量主要来自销售收现；同时应收账款期末净额 21.74 亿元，2 年以上应收余额约 3.02 亿元。现金流已转好，不等于每一笔应收都已转化为现金。

## 三、现金流、库存与减值复核

| 核查项 | 原始财报事实 | 判断 |
|---|---:|---|
| CFO 与归母净利 | 7.7013 / 8.4915 亿元 | 90.7%，未达到 100%，但公允价值收益并不产生经营现金 |
| CFO 与扣非归母 | 7.7013 / 4.1181 亿元 | 187.0%，核心利润现金化良好 |
| 简化 FCF | 7.7013 - 1.2107 = 6.4906 亿元 | 为正；不把 14.0916 亿元的投资支付误当维护性资本开支 |
| 存货总额 / 减值准备 / 净额 | 33.40 / 8.04 / 25.36 亿元 | 准备率 24.07%，对芯片价格下行仍留有高敏感度 |
| 资产减值损失 | 0.1691亿元 | 其中存货 0.1481 亿元、无形资产 0.0209 亿元；上年同期为 1.5052 亿元 |
| 信用减值损失 | 0.0895亿元 | 较上年同期 0.2128 亿元下降，仍须与账龄和回款一起跟踪 |

财报附注七·10（PDF第91页）显示原材料、在产品与库存商品的减值准备均有余额；附注七·73（第125页）确认本期减值主要仍为存货。这不是“零减值”的复苏。

财报没有披露关联交易定价偏离市场的证据，也没有关联方非经营性资金占用；但关联销售集中于单一关联方，下一期应披露其回款、退货及毛利率是否与非关联客户可比。

## 五、管理层表述与承诺追踪

管理层对本期利润高增的归因较具体：需求回升、产品结构优化、公允价值收益和上年高基数减值回落均被分别说明，属于较坦诚的信号。需保留的疑问是，“本期无新增重大减值因素”不等于库存绝对安全，因为期末库存准备率仍上升。

公司没有在中报中给出可据以评分的量化下半年利润指引；本轮不以电话会问答替代正式财报附注。

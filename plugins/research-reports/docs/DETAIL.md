# 研究报告浏览

把本项目 `reports/` 目录下的全部研究报告，按**标的**汇总成一页，默认组内与组间都按时间降序排列；标的可以置顶、拖拽排序，点开任意一篇即可在面板内阅读正文。

## 功能

- **每日监控**：工具栏「每日监控」进入监控视图，列出进入/接近价格区间的标的与待处理披露，详见下文。
- **按标的汇总**：以 `reports/` 的顶层目录作为标的（`腾讯/`、`拼多多/`、`英伟达/`……），顶层散落的报告归入「综合与横评」。
- **分组**：左侧按标的类别分区——公司、专题、大师研究、筛选池、监控、归档。类别来自 `reports/_index/config.json` 的 `companies` / `themes` / `masters` / `screens`；`daily-monitor` 与 `trigger-scan` 属于运行产物而非标的，单独放进「监控」「归档」区（可用插件配置 `bucketOverrides` 改）。
- **时间降序**：每个标的内的报告按日期从新到旧排列；标的本身也按最新一篇的日期排序，最近有更新的排在前面。
- **日期来源**：优先 front-matter 的 `date`，其次文件名里的 `YYYYMMDD`，再次所在目录的日期后缀，再次正文前 15 行的日期；四者都没有时回退到文件修改时间，并用 `~` 前缀标出——这类日期只是文件时间，不参与标的排序的依据（有真实日期的标的优先）。
- **类型标签**：沿用 `tools/reports_index.py` 的规则推断报告类型（研究、财报、公众号、深度系列、横评对比、组织管理、估值仓位、筛选、底稿）。
- **口径一致**：列表里的「N 篇」「最新」「标的排序」和页头汇总都来自同一份「当前可见」的报告集合。隐藏底稿时数字与排序同步变化，不会出现"最新日期对应的那篇看不见"的矛盾。
- **底稿开关**：证据、审计、复算等中间产物标记为「底稿」，默认隐藏；只含底稿的标的会显示 `0` 并提示「N 篇底稿已隐藏」，打开开关即可看到。
- **搜索**：同时匹配标的名称与报告标题；命中标的名称时显示该标的全部报告，命中标题时只显示命中的报告。

### 置顶

- 每个标的一行，行内右侧的图钉按钮把它**置顶到本分类最前**（公司里的标的会排在「公司」区最前，不会跨分类聚合）。
- 置顶块排在分类最前，**新置顶的排在最前**；置顶块与其余标的之间有一条虚线分隔，块内还可以继续拖拽或用 `Alt+↑/↓` 调整先后。再点一次图钉取消置顶。
- 取消置顶后的落点：这个分类**没有**手工顺序时回到按最新日期的自然位置；已经有手工顺序时排到手工顺序的第一条。
- 只点图钉不会冻结同分类其他标的的顺序：新报告更新日期后，未置顶的标的仍按日期浮动，置顶块保持不动。
- 置顶是「本分类内靠前」，不是「跨分类置顶」：分类顺序仍固定为公司 → 专题 → 大师研究 → 筛选池 → 监控 → 归档 → 其他。

### 拖拽排序

- 拖动任意标的行即可调整顺序：在同一区域（置顶块 / 非置顶块）内拖是排序，从非置顶块拖进置顶块等于置顶，从置顶块拖到非置顶块等于取消置顶。
- 只能在本分类内拖动，跨分类拖动不会生效（分类是目录与配置决定的，不由手工排序改变）。
- 拖到列表上下边缘时列表自动滚动，所以「公司」这种 200 多个标的的长分类也能一次拖到底/拖到顶。
- 键盘同样可以排序：标的上按 `Alt+↑` / `Alt+↓` 在当前区块内上移、下移（置顶操作本身是行内图钉按钮）。在置顶块里用键盘只改置顶顺序，不会冻结其余标的的日期顺序。
- 不想拖的话也可以用右键菜单的「移到最前 / 移到最后」，见下一节。
- 搜索状态下拖拽与键盘排序都关闭，避免在筛选结果里写出与全量顺序矛盾的顺序；清空搜索即可继续，导航底部的提示会说明当前能不能拖。
- 一旦在某分类的非置顶区拖过顺序，这个分类就有了「手工顺序」：分区标题旁会出现标记，未置顶的标的按手工顺序排列（新出现的标的排在已列出标的之后），此后新报告的日期变化不再让它们浮动。把该分类的置顶块重新排一遍不会触发这一点。
- 有置顶或手工顺序时，工具栏出现「恢复默认排序」；点一次变成「再点一次确认恢复」（4 秒内不点就还原），二次确认后清空全部偏好，回到按最新日期排序。
- 触屏说明：HTML5 拖拽在触屏浏览器里不可靠（iOS Safari 不触发元素拖拽事件），所以触屏下不显示拖拽把手，导航底部改为提示「图钉可置顶，排序请用桌面端或外接键盘 Alt+↑/↓」。桌面端（本插件的默认场景）拖拽正常，且拖到列表上下边缘会持续滚动。

### 每日监控

- 工具栏的「每日监控」按钮进入监控视图，按钮上直接标出**进入区间 / 接近**的标的数量（例如「进入区间 15 · 接近 7」），不打开也能一眼看到有没有事。
- 视图内容与 GitHub Pages 上的每日监控页同一口径，数据直接读每日监控任务写出的 `reports/daily-monitor/daily-monitor-latest.json`：
  - 顶部：数据截止日、时区、运行状态（OK / DEGRADED）、该次运行的摘要（优先级与新增条数）、四个数据源状态。
  - **价格区间**：默认只列「进入区间（TRIGGERED）」和「接近（NEAR）」的标的，按状态、优先级排序；每行给出标的（点击直接打开对应研究报告）、市场、监控区间、触发条件、现价、距边界、状态标签。点「显示全部」可看包括未接近（FAR）在内的全部价格区间（当前 101 条）。
  - **财报与正式披露**：今天到期 / 逾期 / 待复核的计数，以及最多 12 条待处理事项（标的可点击打开其研究报告），其余条数在完整报告里。
- 监控视图里搜索框同样生效（按标的、市场、区间名过滤）；只要有搜索，就自动看全部价格区间，而不是只看进入/接近。
- 「打开完整监控报告」把 `daily-monitor-latest.md` 交给阅读视图渲染（表格、站内链接、来源链接都在），Esc 从阅读视图退回报告列表，再按 Esc 从监控视图回到报告。
- 找不到 JSON（例如刚从旧提交检出、或监控任务还没跑过）时，视图会说明原因并允许直接打开最新的监控报告。
- 这一视图只读：不写任何监控文件，也不改 `data/triggers.json` 或 `data/monitoring-state.json`。

### 右键菜单

- 在任意标的上右键（键盘聚焦后按 `Shift+F10` 或菜单键）打开操作菜单：置顶 / 取消置顶、移到最前、移到最后。
- 「移到最前 / 移到最后」**只调顺序，不是置顶**：未置顶的标的排到本分类非置顶区的最前或最后，置顶状态不变；已置顶的标的则在置顶块内部移到最前或最后（菜单文案会写成「移到置顶块最前/最后」）。
- 已经是该区第一个或最后一个时，对应菜单项置灰；执行后用页脚提示「已移到最前/已移到最后」。
- 这两项写入的是手工顺序，分区标题会出现「手工顺序」标记，此后该分类未置顶的标的按手工顺序排列（与拖拽一致）。
- 菜单支持方向键上下切换、Enter 执行、Esc 关闭并回到原标的；点击别处、滚动页面或改变窗口大小都会关闭。
- 搜索时的行为：菜单的绝对移动（最前 / 最后）仍然可用——在筛选结果里「最前/最后」的含义不变；相对移动（拖拽、`Alt+↑/↓`）仍然关闭。

### 阅读报告

- 点击报告行（日期、标题、类型标签构成的整行）打开阅读视图：顶栏是返回按钮、标题、日期/类型/标的/路径和「复制路径」，正文在下方滚动。
- 返回的层级：从报告列表点进来时，返回按钮是「返回报告列表」，Esc 同样回到列表；从报告内的站内链接跳到另一篇时，按钮变成「返回上一篇」，Esc 也是退一篇，直到回到列表。
- 阅读位置会记住：每篇报告的滚动位置按路径保存，返回上一篇时回到上次读到的位置，而不是顶部。
- 正文在 Host 端解析成块树再下发，支持标题、段落、粗体/斜体/删除线/行内代码、链接、图片、有序与无序列表（含 `[x]` 任务项）、嵌套列表、引用、GFM 表格（含对齐）、代码块、分隔线。
- 报告内的相对链接：指向本报告树内其他 `.md` 的文章会在同一阅读视图里打开（含 `../快手/...`、带空格的文件名、`<…>` 包裹的地址、百分号编码的中文路径）；从站内链接跳转后返回按钮变成「返回上一篇」，可以顺着链一路退回去；外链在新窗口打开；无法解析的链接降级为纯文本，不会把页面导航走。
- 报告内的图片（如 `assets/xxx.png`）通过资源路由按需加载，限定在 `reports/` 目录内的图片类型；SVG 额外带沙箱与下载语义，直接打开不会在本站执行脚本。
- 切换报告时位置不会串：每篇报告有自己的滚动容器，从一篇跳到另一篇不会继承上一篇的滚动位置。
- 超长报告只读取前 `maxReportBytes`（默认 400 KiB），并在正文顶部说明截断；解析侧还有独立上限：6000 个块、4 万个行内节点、2 万个表格单元、40 层嵌套，超出时保留开头并标注截断——这些上限让任何一篇（含机器生成的）报告都不会卡住 Host。

### 偏好保存在哪里

- 置顶与手工顺序保存在 `~/.dsh/storages/research-reports/ui-state.json`（可用 `statePath` 改），不写进仓库、不进 git，换浏览器仍然生效。
- 写入在拖拽停顿约 0.3 秒后合并成一次；保存成功会在页脚提示「排序已保存」，失败时面板顶部出现提示，当前界面仍按新顺序显示。
- 读取失败（文件损坏、权限问题）时面板顶部提示「读取置顶与排序失败」并给出「重试」，界面按默认顺序显示；此时再次置顶会写入新的合法文件，提示随之消失。保存失败时页脚不会再声称「已保存在本机」。

## 使用

1. 安装后刷新页面，侧边栏多出一个「研究报告」图标。
2. 点击图标，主区域打开面板：左侧按类别列出标的（附每个标的当前可见报告数），右侧是该标的的报告。
3. 点「刷新」重新读取目录；Host 端结果缓存 2 秒，避免连续刷新时重复扫描。

## 数据来源与边界

- 面板读取的是**本地文件系统**上的 `reports/` 目录，不依赖 `git add`，也不依赖 `reports/index.json` 是否最新；尚未提交的本地稿件同样会出现。
- Host 半（`index.js`）在浏览器 HTTP 通道上注册五条路由：
  - `GET /plugin/research-reports/data.json`：一次目录扫描的结果。
  - `GET /plugin/research-reports/report.json?path=`：单篇报告解析后的块树，Host 端缓存 12 篇（按 mtime + size 失效）。
  - `GET /plugin/research-reports/asset?path=`：报告引用的图片，只允许 `reports/` 内的图片扩展名，带 `content-length` / `last-modified`，SVG 额外加 `content-security-policy: sandbox` 与 `content-disposition: attachment`。
  - `GET /plugin/research-reports/monitor.json`：每日监控摘要，读 `daily-monitor-latest.json` 后只保留面板需要的字段（价格区间 + 待处理事项 + 计数 + 数据源），按 mtime/size 缓存，16 MB 上限。
  - `GET|POST /plugin/research-reports/state.json`：读取与保存置顶/排序偏好；写入前校验 JSON 形状与大小，原子替换文件，要求 `content-type: application/json`，并拒绝任何来源不明的写入（`Origin` 与自身不符、`Origin: null`、`sec-fetch-site` 非 same-origin）。
- 读路径的越界防护：先做词法归一化（`..`、绝对路径、编码穿越、NUL 一律拒绝），再对真实路径做一次 `realpath` 包含检查——`reports/` 里就算有人放了指向外部的符号链接，也不会被读出来。
- 报告目录由插件配置 `reportsDir` 指定，默认 `~/stock/ai-berkshire/reports`，在 `cordis.patch.yml` 里改成别的路径即可浏览其他仓库的报告树；路径不存在或没有报告时，面板会显示该路径并提示重试。
- 只统计 `.md` 文件，跳过 `_index`、`__pycache__`、`node_modules`、`.git` 等目录。按项目索引约定，`README.md` 与 `command-log.jsonl` 视为索引/日志文件，不计入报告列表——包括各公司目录下作为研究框架概览的 `README.md`。
- 刷新失败时保留上一次的结果并在顶部提示，不会清空正在看的列表。
- 面板只读报告：不写入、不编辑、不删除任何报告文件；唯一写入的文件是自己的 UI 偏好 JSON。
- 标的分组只认目录层级（最多向下三层），深层子目录名作为「系列」保留在数据里，但界面不展示。
- 解析器只产出固定标签的块树（不产出 HTML），链接只放行 `http(s)`/`mailto` 与树内路径，因此报告内容无法把脚本或外来协议注入面板。

## 自测

```bash
cd plugins/research-reports
node --test "test/*.test.mjs"
```

- `test/markdown.test.mjs`：解析器行为（标题、表格、列表、引用、代码块、链接解析、带空格与 `<…>` 的链接、越界路径降级、截断），病态输入的耗时有上界且容器块不被丢弃，并扫描仓库里的全部报告，断言块类型与结构合法。
- `test/ordering.test.mjs`：置顶与排序的纯逻辑（分区顺序、置顶块、拖拽落点、跨区移动、搜索不影响已存顺序）。
- `test/host-paths.test.mjs`：请求路径解析（`..`/绝对路径/编码穿越/NUL 全部拒绝，符号链接指向树外时拒绝）、偏好状态校验（`__proto__` 等键、非法形状被丢弃）与每日监控摘要（区间措辞、距边界百分比、`../` 研究链接解析、计数与排序），用临时目录，不动仓库里的报告。
